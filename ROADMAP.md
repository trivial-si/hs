# Roadmap

This is a statement of priorities, not a delivery schedule. Discuss larger changes before implementing them.

## Initial public release

- Make installation, backup, and Hamster migration easy to follow.
- Keep existing timer, database recovery, TUI, and agent contract tests passing.
- Publish a Linux x86-64 release with checksums and matching source.
- Welcome a first round of external installation and migration feedback.

## Next priorities

- Improve terminal accessibility, small-window behavior, and keyboard discoverability.
- Grow synthetic migration fixtures for documented Hamster schema-v9 edge cases.
- Test additional Linux distributions and document packaging requirements.

## Discuss before committing

Additional operating systems, database schemas, sync, desktop integrations, and changes to public agent contracts need an agreed design and tests. The initial focus is dependable personal time tracking with local data.
