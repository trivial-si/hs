# Getting help

Start with the [user guide](docs/guide.md), `hs --help`, and the help for the relevant subcommand.

- Ask usage questions and discuss ideas in [Discussions](https://github.com/trivial-si/hs/discussions).
- Report reproducible bugs and scoped feature requests in [Issues](https://github.com/trivial-si/hs/issues).
- Report security issues privately using [SECURITY.md](SECURITY.md).
- Report conduct concerns using [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Include your hs version, Linux distribution, terminal, and a minimal example with fictional records. Do not attach your personal database. Support is provided on a best-effort basis by maintainers and the community.
